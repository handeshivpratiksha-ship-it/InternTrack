# InternTrack

A simple and professional web application to track job and internship applications.

## 🚀 Live Demo

https://handeshipratiksha-ship-it.github.io/InternTrack/

## ✨ Features

* Add job and internship applications
* Track application status
* View application statistics on dashboard
* Edit existing applications
* Delete applications
* Search applications by company or position
* Filter applications by status
* Add application date and notes
* Data saved using browser LocalStorage
* Responsive and clean user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage
* GitHub Pages

## 📊 Application Status

The application supports four statuses:

* Applied
* Interview
* Selected
* Rejected

## 💻 How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## 🌐 Deployment

This project is deployed using **GitHub Pages**.
